# 📝 Daily Manifest

### A Simple and Interactive Daily To-Do Application

**Daily Manifest** is a clean and interactive web-based To-Do application designed to help users organize, manage, and track their daily tasks efficiently.

The application allows users to create tasks, assign priorities, mark tasks as completed, edit existing tasks, delete tasks, filter tasks, and monitor their overall completion progress.

---

## ✨ Features

* ➕ Add new tasks
* 🎯 Set task priority

  * Low
  * Medium
  * High
* ✅ Mark tasks as completed
* ✏️ Edit tasks by double-clicking
* 🗑️ Delete tasks
* 🔍 Filter tasks

  * All
  * Open
  * Cleared
* 📊 Track task completion percentage
* 🚨 Identify high-priority tasks
* 📅 Display the current date
* 🕒 Display the current time
* 💻 Clean and responsive user interface

---

## 🛠️ Technologies Used

| Technology       | Purpose                            |
| ---------------- | ---------------------------------- |
| **HTML5**        | Structure of the application       |
| **CSS3**         | Styling and user interface         |
| **JavaScript**   | Application functionality          |
| **React 18**     | UI components and state management |
| **Babel**        | JSX support in the browser         |
| **Google Fonts** | Typography                         |

React and Babel are loaded through CDN resources, so the project does not require Node.js, npm, or a backend server to run.

## 🚀 Getting Started

### Prerequisites

No special installation is required.

You only need:

* A modern web browser
* An internet connection for the CDN resources

### Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The Daily Manifest application will start automatically.

---

## 🎮 How to Use

### ➕ Add a Task

Enter your task in the input field, select the required priority, and click the **Add** button.

### ✅ Complete a Task

Click the task completion control to mark a task as completed.

### ✏️ Edit a Task

Double-click an existing task to edit its text.

### 🗑️ Delete a Task

Use the delete option associated with a task to remove it.

### 🔍 Filter Tasks

Use the available filters to organize your task list:

* **All** – Displays all tasks
* **Open** – Displays unfinished tasks
* **Cleared** – Displays completed tasks

---

## 📊 Progress Tracking

Daily Manifest provides useful task statistics to help users monitor their daily productivity.

The application displays information such as:

* Number of open tasks
* Number of cleared tasks
* Overall completion percentage
* High-priority task information

---

## 💾 Data Storage

Daily Manifest currently does not use a backend server or database.

Task entries are maintained for the current browser session only. Data may not persist after the browser session ends.
